# BuddyDex v003

- Expand the roster from 452 to **1,017 fully written NPC profiles**, with researched lore, distinct personalities, favorite emotes and personal dialogue across Alliance and Horde communities.
- Add more companions throughout starting areas, cities and travel hubs, including Forever-specific characters. Seasonal NPCs remain seasonal discoveries.
- Fix friendship bars so the frame stays above the colored fill.
- Add personal recordings for Martha Strain and Krog, plus additional Forsaken shared dialogue.

**Voice coverage is still in progress.** 454 profiles have initial personal recordings; 563 additional profiles currently use written dialogue while their recordings are prepared. Initial recordings do not mean every line is voiced. Missing recordings remain readable in speech bubbles.

Friendships and unlocks remain specific to each character. Normal friendship eligibility still applies; children and generic unnamed guards are excluded.

The complete development history and NPC research notes are available in the GitHub repository.
